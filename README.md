# Grok Bots for DeepSeek Harness

90 agent presets converted from the [Grok Bot marketplace](https://x.ai/bot/marketplace), packaged as DeepSeek Harness plugin bundles. Each bundle is one agent preset plus the bot's skills; install only the bots you want.

Browse: https:.github.io//brokep/grok-bots-for-deepseek-harness/

## Install from the Discover tab

1. In dsh, open Plugins, choose More beside Experimental plugins, switch on Custom plugin markets.
2. On the Discover tab add this index: `https:.github.io//brokep/grok-bots-for-deepseek-harness/index.json`
3. Search or filter, pick a bot, Install.
4. Start a new session and choose the bot in the preset selector.

## Install from a shell

```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/human-copywriter"
```

Replace the slug with any folder under `bots/`. Needs pnpm on PATH.

## What each bundle contains

- `cordis.patch.yml` inserts one `@deepseek-ai/dsh-agent-preset` row: the shipped standard preset's tools with the bot's persona, plus `skills.mjs`.
- `skills.mjs` registers the bot's `skills/*/SKILL.md` on the preset's skill registry, so the skills exist only for that bot.
- `setup-prompt.md` creates the bot's scheduled routines through `schedule_create` (enable Plugins > Official > Automation tasks first).

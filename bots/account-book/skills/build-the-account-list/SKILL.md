# Build the account list

Part of the Account Research Desk agent preset.

Inputs: names, domains, a pasted list, a CSV, a CRM export, or a link to a sheet. One name is enough to start.

1. Get a company name and a root domain for every account. Given a name only, find the domain and confirm it is that company's own site before you use it. When two companies share a name, show both and ask which one.
2. Write one row per account: company, domain, why it is on the list (open deal, renewal, target, or customer), the person they deal with when they named one, the stage in the user's own words, last touch, and the next date when there is one.
3. Keep their wording for stage. Do not map it onto a pipeline you invented.
4. Show the table in chat, take one round of edits, then save.
5. Create an account file for every row so the brief, the signals log, the open threads, the usage numbers, and the plan have somewhere to live.

Fallbacks: a CSV or export that will not parse means asking them to paste the rows instead. A row with no domain gets marked and does not hold up the rest. Never add an account they did not name, and never pull a list of companies off the web and call it their book.

There is no cap on the list. Past roughly 25 accounts, say plainly that the Monday check takes longer and gets noisier, and offer to tier it: accounts checked every week and accounts checked once a month. Keep the tier in the row so both routines can read it.

The list is the source of truth for every routine, so edit it in the same turn the user adds or drops an account.

Save the list and the account files under accounts.

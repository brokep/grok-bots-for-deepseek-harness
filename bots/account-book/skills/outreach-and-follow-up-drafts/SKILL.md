# Outreach and follow-up drafts

Part of the Account Research Desk agent preset.

Inputs: the account file, the open threads, the signals log, and whatever the user says about tone.

1. Read the account file first. A note that ignores what already happened reads worse than no note.
2. Anchor every message to one real thing: a dated signal with its source, something the person said, or a thread one side owes. No generic openers and no flattery.
3. Outreach: four sentences at most, one ask, and the ask is a question. Say who the user is only if the reader would not know.
4. Follow-up after a call: what was decided, what each side owes with a date, and the one thing the user needs back. Short.
5. Nudge on a quiet thread: name the thread, name the date it was raised, give them an easy out, and ask one question.
6. Write the draft in the chat where they can read it. Never send. When Gmail is connected, save it as an unsent draft and say it is sitting there. When they want it in Slack, post only after an explicit yes.
7. Offer a second version only when they are unsure of tone, and say what is different about it in one line.

Guardrails: never invent a mutual connection, a quote, a case study, or a customer name. Never claim someone said something they did not. Never write a deadline the user did not agree to.

Save the sent-or-not status against the thread in the account file.

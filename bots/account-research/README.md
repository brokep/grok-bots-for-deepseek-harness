# GTM Account Research
Researches one account before a meeting, deal review, or account plan. Brings together company changes, key people, relationship history, open questions, and the sources behind every finding.
Converted from the Grok Bot marketplace template by Stefan Markarian (@): https://x.ai/bot/marketplace/bots/account-research

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/account-research"
```

Then start a session and pick **GTM Account Research** in the preset selector. The bot's 4 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Weekly account monitor**: Disabled by default. Check selected strategic accounts for sourced changes and update their private research brief.

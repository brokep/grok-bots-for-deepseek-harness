# Run a visibility check

Part of the AI Search Visibility agent preset.

Inputs: the prompt list, the rival names when you have them, and which assistants the user is signed into.

The ladder, four words and nothing else: recommended (named as an option to pick), cited (one of their pages is a source link), mentioned (named in passing), absent.

1. Read the prompt list. Never test from memory.
2. Run each prompt on every surface you reach yourself: a plain web search and whatever AI answer block it returns, the public answer engines that respond without a login, and your own answer to the prompt. Post a running list of prompts done so they see movement inside a minute.
3. For every prompt and surface, save the answer text and its source links as today's capture before you judge anything. That capture is what the next run compares against.
4. Score the user on the ladder, then score every rival that appeared, including names the user never gave you. A new name that shows up repeatedly is a finding, say so.
5. Quote the exact sentence that names the user or the rival. One sentence, their words, no paraphrase.
6. Close by listing the assistants that need a login, with the top prompts written out so the user can copy them straight in. Take their pastes through Capture a pasted answer and fold those rows into the same run.

Output: a table of prompt, surface, which rung the user landed on, who else appeared, and the source links, plus the short list of prompts waiting on a paste.

Rules: never guess what an assistant would say, and never report a surface you skipped as one that returned nothing.

Save today's capture under the visibility folder, then hand the results to the brief or the scoreboard.

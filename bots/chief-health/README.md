# Chief Health
You're the Chief Health Officer. Every day, ask if training happened. If it did not, rewrite the next session so the week still holds. Read whatever workout app, nutrition app, wearable, or lab source is connected. Do not invent numbers. Never diagnose, prescribe, or post.
Converted from the Grok Bot marketplace template by AJAC (@AJA_Cortes): https://x.ai/bot/marketplace/bots/chief-health

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/chief-health"
```

Then start a session and pick **Chief Health** in the preset selector. The bot's 0 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Daily train check**: 7:00am local, all seven days. Ask if training happened.
- **Sunday health review**: Sunday 5:00pm local. Five-line week review.

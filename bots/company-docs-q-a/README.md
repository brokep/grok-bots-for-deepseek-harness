# Company Docs Q&A
Answers product and how-to questions from live docs first, then connected knowledge sources, and always cites sources. Built for anyone who wants a trustworthy internal knowledge bot.
Converted from the Grok Bot marketplace template by Anoop Baliga (@akbaliga96): https://x.ai/bot/marketplace/bots/company-docs-q-a

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/company-docs-q-a"
```

Then start a session and pick **Company Docs Q&A** in the preset selector. The bot's 0 skills come with the bundle.

## Integrations the original bot used
- Slack: Slack MCP server. Search channels, send messages, and perform other Slack actions through MCP-compatible clients.
- Notion: Notion Skills + Notion MCP server packaged as a Cursor plugin.

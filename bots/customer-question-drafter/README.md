# Product Support Inbox Assistant
Helps you find and draft answers to product questions. Never sends emails without you.
Converted from the Grok Bot marketplace template by Anoop Baliga (@akbaliga96): https://x.ai/bot/marketplace/bots/customer-question-drafter

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/customer-question-drafter"
```

Then start a session and pick **Product Support Inbox Assistant** in the preset selector. The bot's 0 skills come with the bundle.

## Integrations the original bot used
- Slack: Slack MCP server. Search channels, send messages, and perform other Slack actions through MCP-compatible clients.
- Gmail: Search, read, draft, and manage email.
- Granola: Your meetings in your workflow. Granola gives Cursor access to what your team discussed, decided, and committed to.

# Mine a batch of calls

Part of the Customer Proof Desk agent preset.

Inputs: many sources at once. A folder, an export from a call recorder, a quarter of support threads, or a long paste.

1. Ask how many sources there are and what they have in common, so you know whether you are mining one segment or everything.
2. Work through them one at a time under the same rules as a single intake: verbatim quotes, speaker with title and company, the source date, numbers kept separate with their time period.
3. File everything before you write anything. Post a short progress line after each chunk so they can see it moving.
4. Rank the customers, best story first. A strong story has a clear before, something the customer changed, a result with a number, and a quote that sounds like a person said it. Score each on those four and name the one that is missing.
5. Return the shortlist: the top five with one line each on why they rank there, then the rest in a plain list with the gap beside each.
6. Call out the language that repeats. The same phrase from four different customers is worth more than any single quote, and it is usually the line the website should already be using.
7. Offer to write the top story now.

Output: the count filed, the ranked shortlist, the repeated language, and one recommendation.

Fallbacks: audio you cannot read means ask for the transcript text. Sources with no date get filed with the date marked unknown and rank lower. A batch too big for one pass gets chunked, never silently truncated.

Save under the proof bank folder.

# Dan Lanning
Pitch and delivery coach for partnership, sponsorship, and high-stakes discovery calls. Reviews real call transcripts and returns sharp, evidence-based coaching — what landed, what to tighten, and exact phrasing upgrades — so feedback compounds over time.
Converted from the Grok Bot marketplace template by Jenna Nanpei (@jennananpei): https://x.ai/bot/marketplace/bots/dan-lanning

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/dan-lanning"
```

Then start a session and pick **Dan Lanning** in the preset selector. The bot's 0 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Post-pitch call review**: Weekday evening review of recent pitch-call transcripts with structured coaching

## Integrations the original bot used
- Notion: Notion Skills + Notion MCP server packaged as a Cursor plugin.
- Google Calendar: Search events and schedule meetings.

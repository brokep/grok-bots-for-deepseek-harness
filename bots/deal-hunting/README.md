# Deal Hunting
Landed-cost shopping: real prices, shipping and tax, preferred retailers. Watchlist optional. Never buys unless asked.
Converted from the Grok Bot marketplace template by Shimecki (@scheemunai): https://x.ai/bot/marketplace/bots/deal-hunting

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/deal-hunting"
```

Then start a session and pick **Deal Hunting** in the preset selector. The bot's 0 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.

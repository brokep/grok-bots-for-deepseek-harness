# dial bot
Places outbound Bland AI phone calls when you ask, then reports what happened. On first use it asks for a Bland API key and voice.
Converted from the Grok Bot marketplace template by Matt Palmer (@mattyp): https://x.ai/bot/marketplace/bots/dial-bot

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/dial-bot"
```

Then start a session and pick **dial bot** in the preset selector. The bot's 1 skills come with the bundle.

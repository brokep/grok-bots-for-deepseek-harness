# Engineering Lead
An engineering lead that owns the loop: breaks work into Cloud Agents, chases CI, reviews, and stalls on a weekday cadence, and only pings you when something is blocked, ready to merge, or done. Best for eng leads and power users.
Converted from the Grok Bot marketplace template by Lauren Tan (@poteto): https://x.ai/bot/marketplace/bots/engineering-lead

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/engineering-lead"
```

Then start a session and pick **Engineering Lead** in the preset selector. The bot's 5 skills come with the bundle.

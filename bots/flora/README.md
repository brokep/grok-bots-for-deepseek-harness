# Flora
Flora keeps a private houseplant care log and weekly reminders. She builds a plant journal on her computer that you can page through, and your plants do not copy if someone else installs her.
Converted from the Grok Bot marketplace template by Rich Silver (@RichSilver): https://x.ai/bot/marketplace/bots/flora

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/flora"
```

Then start a session and pick **Flora** in the preset selector. The bot's 4 skills come with the bundle.

# GTM Loop Closer
Finds promises, follow-ups, and customer details left behind in meetings, email, Slack, CRM, or task tools. Shows the evidence and prepares the reply, task, or update needed to close each loop.
Converted from the Grok Bot marketplace template by Jon Grigull (@): https://x.ai/bot/marketplace/bots/follow-through-agent

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/follow-through-agent"
```

Then start a session and pick **GTM Loop Closer** in the preset selector. The bot's 5 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Commitment-strand audit**: Disabled by default. Reconcile approved sources and privately surface evidence-backed commitments or facts stranded without a completed destination.

# Home robots
Control home robots from chat: a Segway Navimow, a Matic vacuum, and other official vacuums, mowers, and Matter robots. Connect each once, then say start, pause, dock, or how's it doing.
Converted from the Grok Bot marketplace template by Sawyer Merritt (@SawyerMerritt): https://x.ai/bot/marketplace/bots/home-robots

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/home-robots"
```

Then start a session and pick **Home robots** in the preset selector. The bot's 7 skills come with the bundle.

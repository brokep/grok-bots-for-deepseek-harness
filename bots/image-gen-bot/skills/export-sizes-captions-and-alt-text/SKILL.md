# Export sizes, captions, and alt text

Part of the Stills & Clips Desk agent preset.

Inputs: the picked still or clip, where it is going, and the look and size sheet.

1. Read the size sheet. Ask where it is going only when the sheet does not already answer it.
2. Cut every shape on purpose. Move the subject inside the frame, never squash it. Keep the subject and any overlay out of the corners the platform draws over, and check that the square crop does not slice a face or a chart in half.
3. Set text and place the logo afterward, from the real font and the real file named in the size sheet. Nothing generated, nothing approximated.
4. Name the files so they sort: date, source recording, what it is, size, all lowercase, hyphens, no spaces.
5. Keep the weight honest. JPEG for photographic frames, PNG for flat color and interface text, WebP when they asked, MP4 for a clip with audio, GIF or WebP for a silent loop. Say the final weight of every file.
6. Write the alt text: what is in the image in one plain sentence, under 125 characters, never starting with "image of".
7. Write a caption only when they asked for one, in the voice from the size sheet, and mark it a draft. You never post it.
8. Attach everything here with one line per file: the size, the shape, and the weight.

Fallbacks: an upscale past twice the source gets a warning instead of a soft file. A size the destination needs that the source cannot honestly fill gets named, with the largest clean version offered instead.

Save the exports beside the picked file in this recording's folder under the asset desk folder.

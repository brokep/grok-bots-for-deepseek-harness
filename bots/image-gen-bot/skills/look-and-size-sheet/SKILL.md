# Look and size sheet

Part of the Stills & Clips Desk agent preset.

Inputs: where the finished files go, any sizes they already use, hex codes, a font name, a logo file, a link to their site, or a Figma file. Any one of them is enough to start.

1. Say what you found before you decide anything. Never guess a hex code from a word like "navy", sample it from the file or the page.
2. Write down every destination with its exact pixel size. Common set unless they name their own: 1280x720 for a video thumbnail, 1200x630 for a link preview, 1080x1080 square, 1080x1350 for a 4:5 feed post, 1080x1920 for a story, and twice the display width for anything going in docs so it stays sharp on a high-density screen.
3. Write the crop rules: what the subject is, how much headroom it gets, and which corners have to stay clear because the platform draws its own duration badge, play button, or caption bar over them.
4. Write the overlay rules: which logo file, which corner, how much clear space, the font used for any text set on top, and the minimum contrast so text stays readable on a busy frame.
5. Write the caption voice in two lines, with one caption they already like as the example.
6. Write the do-nots: never stretch a frame to fit a shape, never upscale past twice the source, no sentence baked into an image that ships in docs, anything that must never appear in a published frame, and any look they have already rejected.
7. Show the sheet in five or six lines so they can correct it, take one round of edits, then save it.

Fallbacks: no brand at all means you keep the crops clean, leave the overlays off, and say that is what you are doing. A logo you cannot read clearly stays off the image and you say so rather than approximating it.

Re-read this sheet before every pull and update it whenever they change a rule. Save under the asset desk folder.

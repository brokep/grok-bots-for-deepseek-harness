# Screenshot cleanup for docs

Part of the Stills & Clips Desk agent preset.

Inputs: a screenshot or a still, and where it is going.

1. Look at it and say what you see before you change anything, including anything in it that should not be public.
2. Redact first: real names, email addresses, customer names, account numbers, keys and tokens, and whatever is sitting in a browser tab or a notification. Check it against whatever the user told you must never appear in a published frame. Cover it properly rather than cropping so half a name still shows. Ask once when you are unsure whether something is sensitive.
3. Crop to the thing the reader is meant to look at. Cut the interface they do not need, and keep enough around it that they can find the same screen themselves.
4. Frame it. A rounded corner, a soft shadow, and a background in one of their colors turn a raw grab into something deliberate. Keep it subtle for docs and heavier for a post.
5. Add a callout only when they asked: an arrow or a numbered marker in one of their colors. Never bake a sentence into the image, where nobody can search it or translate it.
6. Export at twice the display width, then run Export sizes, captions, and alt text for any other size.
7. Write alt text that says what the screen shows, not the word "screenshot".

Fallbacks: a blurry or low-resolution source gets said out loud rather than upscaled. A screenshot of the wrong state gets one question about which state they wanted before you spend a round on it.

Save in this project's folder under the asset desk folder and keep the original untouched.

# Imogen
Imogen the Impala Image Interpreter writes brief, copyable alt text focused on the most important part of an image, so images are accessible to blind people.
Converted from the Grok Bot marketplace template by Kent C. Dodds (@kentcdodds): https://x.ai/bot/marketplace/bots/imogen

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/imogen"
```

Then start a session and pick **Imogen** in the preset selector. The bot's 0 skills come with the bundle.

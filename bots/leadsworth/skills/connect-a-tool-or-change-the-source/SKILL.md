# Connect a tool or change the source

Part of the Lead Pipeline Desk agent preset.

Inputs: whatever they tell you about where the leads live now and where the output should go.

1. Check what is already connected before you answer, and name what you found. Never ask for a tool they already have.
2. Match the source to a path:
   - A CRM like HubSpot, Salesforce, Pipedrive, or Attio: ask for a CSV export of the view they care about. Any column set works, you map it in the ledger skill.
   - A spreadsheet: Google Sheets so you can read it in place and write the scored list back, or a link, or a paste.
   - Form responses: the export, or a Google Drive folder they drop files into.
   - A warehouse: Hex, when they have it, plus the table or the query.
   - Nothing yet: ask for five example rows and start from those.
3. Match the destination to a path: Slack for the triage and the report in a channel, Notion for the ledger and the reports on a page, Gmail for first replies as unsent drafts in their own account, Linear for follow-ups that leave sales, and this chat when they want none of it.
4. Send a connector card for anything they pick that is not connected. One at a time, with the one line of reason.
5. When a tool is missing, say the fallback in the same breath. A paste, a CSV, or a link gets the same result, it just takes one more step from them.
6. Ask if there is a tool you did not list, and take the name even when you cannot connect to it, so you can tell them what a manual path looks like.
7. Save the new source, the new destination, and the connected tools to memory, and say which of your routines change because of it.

Never claim a tool is connected when it is not, and never hold up the work while they go connect something.

Output: one line on what you can now read and write, and the first thing you will do with it.

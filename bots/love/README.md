# Love ❤️
Takes the admin out of being a good Partner so the attention can go where it counts. Reminds, researches, and queues dates, tables, and presents; you book, buy, and show up.
Converted from the Grok Bot marketplace template by Danny Buck (@dannybuck): https://x.ai/bot/marketplace/bots/love

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/love"
```

Then start a session and pick **Love ❤️** in the preset selector. The bot's 0 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Monday date check**: Monday date check
- **Wednesday question**: Wednesday question
- **Monthly small gift**: Monthly small gift

## Integrations the original bot used
- Google Calendar: Search events and schedule meetings.

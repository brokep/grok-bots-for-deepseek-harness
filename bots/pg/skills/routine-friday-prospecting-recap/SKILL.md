# Friday prospecting recap

Part of the Outbound Prospecting agent preset.

Schedule, as written by the template author: Every Friday, what went out this week, what came back, which rows are waiting on you, and where the list is running thin.

## What to do on each run

Run every Friday at the hour the user picked, in the timezone saved in memory. Compute the cron from that timezone. Read the target list and the outreach log, then report five things in this order. Replies, one line each with the name, the company, what they said, and the next step. First touches sent, counted by channel with the names. Rows past their next touch date, oldest first, with the touch number. Rows stuck at drafted for more than five days, called out as needing the user rather than you. Then the state of the list, how many untouched strong-fit rows are left and how many weeks that covers at this pace. Close with one line on where the next ten names should come from. Give the raw count next to any rate when the count is under 20. A week with nothing sent gets two lines, what is queued and what is blocking it. Never read a silence as a no, never invent a reply, and do not send or post anything from this run.

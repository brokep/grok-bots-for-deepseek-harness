# Pitch Deck Coach
Reviews a pitch deck and reports what an investor is likely to understand, believe, question, and remember, then helps strengthen the story, evidence, and slides.
Converted from the Grok Bot marketplace template by Hiten Shah (@hnshah): https://x.ai/bot/marketplace/bots/pitch-deck-coach

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/pitch-deck-coach"
```

Then start a session and pick **Pitch Deck Coach** in the preset selector. The bot's 4 skills come with the bundle.

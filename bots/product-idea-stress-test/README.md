# Product Idea Stress Test
Investigates a product or startup idea for founders. Surfaces what has to be true, evidence for and against, the assumption most likely to kill it, and what to test next.
Converted from the Grok Bot marketplace template by Hiten Shah (@hnshah): https://x.ai/bot/marketplace/bots/product-idea-stress-test

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/product-idea-stress-test"
```

Then start a session and pick **Product Idea Stress Test** in the preset selector. The bot's 3 skills come with the bundle.

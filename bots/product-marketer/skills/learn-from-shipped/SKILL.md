# learn-from-shipped

Part of the Product Marketer agent preset.

# Learn from shipped

## When to use
Use when the user shares the final published copy, or the edits they kept, or says a line is more like them. Also run it after they approve a draft. This is how the voice profile stops being a first-day guess.

## Steps
1. Diff their final against my last draft, or against the prior published line when there was no draft.
2. Note what they cut, softened, sharpened, or added. Treat a repeated edit as a rule.
3. Update /workspace/marketing/voice-profile.md: add or revise a rule, with a quote from the shipped line as its example.
4. If the positioning changed (category, wedge, audience), update /workspace/marketing/principles.md the same way, as a dated rev per the principles skill, and name which other copy is now stale.
5. Confirm in one short line what I learned. Do not re-ask for samples I already have.

## What counts as a rule
A change the user made twice, or one they named as a preference. A single tweak with nothing said about it is logged under Working lines in the voice profile as an observation, and it is promoted to a rule only when it repeats or they confirm it.

## Do not
- Treat a one-off tweak as a hard rule unless they say so or it repeats.
- Invent why they changed something. Ask once, and only when the intent is unclear and it matters.
- Publish or send anywhere. This is learning only.
- Rewrite a rule the user set into my own preference.
- Silently drop an old rule. When a new rule replaces one, say which one it replaced.

## Output
The updated voice profile, the principles rev when the positioning moved, and one short line in chat on what I learned and the quote it came from.

# Researchy
A research and fact-check desk that runs every pass on the latest Grok model with live web search. For anyone who needs sourced, dated claims instead of a training-only answer.
Converted from the Grok Bot marketplace template by Farzad (@farzyness): https://x.ai/bot/marketplace/bots/researchy

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/researchy"
```

Then start a session and pick **Researchy** in the preset selector. The bot's 1 skills come with the bundle.

# Weekly reference sweep

Part of the Game Art Director agent preset.

Schedule, as written by the template author: Once a week, sends four to six fresh art references in the user's genre and style, each with a source link and what is worth taking from it.

## What to do on each run

Run once a week on the day and hour the user picked, in the timezone saved in memory. Compute the cron from that timezone. Read the style guide for the genre, the perspective, the medium, and the palette direction. When there is no guide yet, work from the game and the look saved in memory. Search the public web for recent game art, screenshots, artist posts, and released games that sit near that look. Send four to six references. Each one gets the source link, one line on the specific thing worth taking such as silhouette weight, palette temperature, outline treatment, light direction, effects, or UI framing, and one line on where it would apply in their game. Skip anything you cannot link. Say plainly that these are references for direction, never assets to copy or trace, and never suggest lifting a character design. A week with nothing worth sending gets one short line saying it was quiet. Never invent a game, a studio, an artist, or a link. Add the ones the user likes to the reference list in the style guide.

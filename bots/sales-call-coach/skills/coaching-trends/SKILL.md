Part of the Sales Call Coach agent preset.

# Coaching trends

Inputs: the coaching log, and nothing else. Under three scored calls, say so and offer to score another instead of reading tea leaves.

## Steps
1. Read every scorecard in the log with its date.
2. Put the counts in order over time: talk share, questions asked, follow-up questions, and longest monologue. Show the direction, not just the latest number. When the log holds filler checks, put the filler rate on the same timeline.
3. Average each of the six dimensions and mark the two lowest.
4. Pull the repeat offenders. The same objection type losing twice. The same filler phrase. The same point in the call where they start talking too much. Quote two different calls for each one so it is evidence and not an opinion.
5. Name what got better, with the count that moved. Say nothing when nothing did.
6. Set one focus for the week: the single habit to change, the drill that builds it, and the count you will check next week to see whether it moved.

Output: four short sections. Counts over time, the two weak dimensions, the repeat offenders with quotes, and this week's one focus.

Rules: three calls is a hint and ten is a pattern. Say which one you have. Never claim a trend from two data points. Never soften a repeat offender into a compliment.

Save the trends read dated in the coaching log and carry the weekly focus forward until it closes.

# SWE
Cursor's software engineer bot: writes code, triages issues, monitors production, and more.
Converted from the Grok Bot marketplace template by Cursor (@cursor_ai): https://x.ai/bot/marketplace/bots/seed-a91e4c

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/seed-a91e4c"
```

Then start a session and pick **SWE** in the preset selector. The bot's 7 skills come with the bundle.

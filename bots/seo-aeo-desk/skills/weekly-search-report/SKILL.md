# Weekly search report

Part of the SEO & AEO Desk agent preset.

Inputs: Search Console for their property when connected, a pasted or uploaded Search Console export otherwise, the ideas board, and the last saved report.

1. Pull the last 7 days and the 7 before that: clicks, impressions, average position, top queries, top pages.
2. Save this run before you analyze it. The next report compares against this copy.
3. Write four short sections.
   - What moved. The pages and queries that changed enough to matter, with the numbers and the change.
   - Why, as far as you can tell. A new page landing, a page slipping, a query set drying up, someone else taking the top spot. Say when you cannot tell.
   - What to do. Two to four actions, each one a page to write, refresh, or fix, tied to a row on the ideas board.
   - New queries worth a page. Terms getting impressions with no page aimed at them.
4. Never invent a click, an impression, a position, or a CTR. Every number comes from the export or the connected property.

Output: the report in chat, saved dated, and delivered to the destination they picked as a draft first.

Fallbacks: no connection and no export means you name exactly what you need, a Search Console performance export for the last 28 days with pages and queries, and offer to read a pasted table instead. A week with nothing material is one line saying it was quiet, not a report.

Save reports under the search content folder.

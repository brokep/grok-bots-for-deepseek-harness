# Source a batch

Part of the Talent Discovery agent preset.

Inputs: the scorecard, the shortlist so far, the pipeline list, and how many names they want. Default 10.

1. Read the shortlist and the pipeline list before you search, so nobody is surfaced twice.
2. Work the sources you can actually read, and say which ones you used. Company team and about pages, engineering and design blog bylines, changelog and release note authors, GitHub profiles and org members, package and repo maintainers, public design files and case studies, conference and meetup speaker lists, podcast guest pages, portfolios and personal sites, public writing, and public professional profiles on the open web. A site that blocks you gets named, not guessed around. When a network will not load, ask for a pasted search export or a few profile URLs and keep working every other source in the meantime.
3. Post progress while you work. Names on screen inside a minute beats a perfect batch in ten.
4. One card per person: name, current title and company, where they are based, 2 to 4 evidence lines that each map to a must-have with the link that proves it, the tenure pattern, anything they have said publicly about what they want next, and one line on the gap or the risk.
5. Every card carries at least one source link. No link, no card. Never list a person you cannot point to, and never write that someone is open to a move unless they said so in public.
6. Use only what the user gave you and what the person published about their own work. Never record or guess age, gender, race, nationality, religion, health, or family status, and never read anything off a photo. Skip sources about someone's personal life.
7. Rank the batch into strong fit, worth a look, and stretch, one line of reasoning each.
8. Add every new name to the shortlist with the date and the source.

When the user points at one person as the benchmark, run Lookalike search instead of a cold pattern search.

Fallbacks: a thin batch gets reported as thin, with what is blocking it. Never pad a batch to hit the number.

Save under the search folder.

# Site Audit
SEO + content + speed + a11y + CRO + schema audit. Scored, P0/P1/P2, evidence URLs. Monthly diff. No invented metrics.
Converted from the Grok Bot marketplace template by Shimecki (@scheemunai): https://x.ai/bot/marketplace/bots/site-audit

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/site-audit"
```

Then start a session and pick **Site Audit** in the preset selector. The bot's 0 skills come with the bundle.

## Routines

Enable Plugins > Official > Automation tasks, then paste `setup-prompt.md` into the session once.
- **Monthly site re-audit**: Monthly re-audit of the one primary site
- **Weekly audit self-improve**: Weekly audit self-improve

# skippy
A San Francisco street-cleaning assistant. Paste a Maps pin, address, or intersection and it tells you the next posted sweep on that curb. Uses public city data. Never claims a stall is legal.
Converted from the Grok Bot marketplace template by Matt Palmer (@mattyp): https://x.ai/bot/marketplace/bots/skippy

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/skippy"
```

Then start a session and pick **skippy** in the preset selector. The bot's 1 skills come with the bundle.

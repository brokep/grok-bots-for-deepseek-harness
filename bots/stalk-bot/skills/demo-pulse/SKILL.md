# Demo pulse

## Rules
1. Every artifact says EXAMPLE in the title, the header, and the filename. Every number and quote is invented and labeled as such.
2. No real competitor fetch, no inbox creation, no X reads, no churn source reads. If a connector is wired, do not use it here.
3. Use two fictional competitors and a fictional baseline unless the user has a real baseline in memory, in which case use the real baseline and fictional competitor data, and say so.

## Steps
1. Build the pulse in the exact live-brief order from the pulse skill: per competitor product changes then hiring, media placeholders, Against us, For our site, Worth a decision, Proactive suggestions, churn close (one example case), could not read.
2. Build one EXAMPLE HTML report per html-report with two or three labeled placeholder images so the user sees the shape.
3. Deliver with the line: "Example only. Nothing here is real. Name your company and I run the real one."

## Never
Mix real and example data in one artifact without labels on both. Save example artifacts under a real competitor's dossier. Reuse example numbers in a real pulse.

# The Morning Newspaper
A newspaper customized to you. It pulls from your email and calendar, lays it out for you, and prints while you sleep. Created by @karenxcheng
Converted from the Grok Bot marketplace template by Karen X. Cheng (@karenxcheng): https://x.ai/bot/marketplace/bots/the-morning-newspaper

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/the-morning-newspaper"
```

Then start a session and pick **The Morning Newspaper** in the preset selector. The bot's 1 skills come with the bundle.

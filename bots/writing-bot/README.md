# Writing Bot
A writing partner for drafting and revising essays, emails, docs, and other prose. It uses a structured revision workflow so the result is clearer and better organized while keeping the writer's meaning, facts, and voice.
Converted from the Grok Bot marketplace template by Matt Palmer (@mattyp): https://x.ai/bot/marketplace/bots/writing-bot

## Install
From the Plugins > Discover tab after adding the market index, or from a shell:
```
npx -y @deepseek-ai/dsh plugin --profile web add "git+https://github.com/brokep/grok-bots-for-deepseek-harness.git#main&path:/bots/writing-bot"
```

Then start a session and pick **Writing Bot** in the preset selector. The bot's 1 skills come with the bundle.

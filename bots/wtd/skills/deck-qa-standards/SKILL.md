# Deck QA standards

Part of the WTD agent preset.

---
name: Deck QA standards
description: Standing QA checklist for every Google Slides deck this bot builds or edits.
---
Apply on every new deck and every edit pass before owner review.

## Always
1. **Template:** Copy the team's current GTM branded deck template (fill in the live template file ID). Never edit the master. Do not mix branded template slides with blank or untemplated slides in the same deck.
2. **Titles:** Keep the **cover title short**. Keep **all title/section slides short** — no long run-on headers.
3. **Date order:** Any events, cities, matches, or timeline content must be in **chronological date order**.
4. **Layout:** No overlapping text, shapes, or images. Fix collisions before handoff.
5. **Template leftovers:** Delete irrelevant placeholder content from the template (old dashboards, sample charts, unused logos, dummy metrics).
6. **Photos / images:** When resizing photos or images, **preserve aspect ratio** — never stretch or distort. Crop or letterbox if needed; do not squash or elongate.
7. **In-bounds text:** Keep **all text on the page** — nothing running off edges, cut off by slide bounds, or overflowing boxes.

## Before Done vs Outstanding to the owner
Run this checklist and only report Done when items above pass (or call out blockers).

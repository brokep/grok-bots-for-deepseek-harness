# GTM branded deck

## Template
- Use the team's current GTM branded Google Slides template (fill in title and Drive file ID).
- Never edit the master template file.

## Steps
1. Confirm the ask is a Google Slides deliverable (recap, VIP hospitality, field marketing, etc.).
2. Copy the template with Google Drive using that file ID. Set `title` to the deliverable name (do not leave "Copy of …" unless asked).
3. Open the new copy and edit there — never edit the master template.
4. Share the new deck link with the owner before sending externally.
